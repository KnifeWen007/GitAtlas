# 交互规格：零命令行、拖拽、连线

这份文档是所有"界面长什么样、怎么动"的准绳。原则：**任何需要在终端里做的事，界面上都必须有一个对应物；任何图形元素，都必须有语义。**

---

## 1. 首次启动：三个入口，全程零输入

```
┌──────────────────────────────────────────────────┐
│              GitAtlas                            │
│   把仓库变成一张能看懂的图                        │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │ 📁 打开   │  │ 📥 克隆   │  │ 🔗 连接   │       │
│  │ 本地仓库  │  │ 远端仓库  │  │ 团队服务器│       │
│  └──────────┘  └──────────┘  └──────────┘       │
│                                                  │
│  最近打开：payment-service · 2 小时前            │
└──────────────────────────────────────────────────┘
```

| 入口 | 交互 | 注意事项 |
| --- | --- | --- |
| 打开本地仓库 | 系统目录选择器 → 校验 `.git` 存在 | 选到子目录时自动向上找到仓库根，并提示"已定位到仓库根目录" |
| 克隆 | 粘贴 URL（唯一允许的文本输入）→ 选保存位置 → 凭据从钥匙串取或弹 OAuth | URL 校验后显示"将克隆 main 分支，约 24MB" |
| 连接服务器 | 输入服务器地址 → 浏览器 OAuth 回跳 | 一次性配对码，避免手输长 token |

**索引过程必须分阶段可见**（不能是一个转圈）：

```
① 扫描分支与标签        ✓  24 个 ref
② 解析提交历史          ████████░░  38,412 / 52,000
③ 计算聚合与热区        ░░░░░░░░░░  等待中
④ 检查问题规则          ░░░░░░░░░░  等待中
```

可"后台继续"，托盘图标显示环形进度；完成后弹系统通知（可关）。

## 2. 零命令行操作映射表

这是"完全不输入指令"的兑现清单。**危险级决定确认方式，不决定能不能做。**

| 操作 | 界面入口 | 危险级 | 确认方式 |
| --- | --- | --- | --- |
| 克隆 | 首屏卡片 | 低 | 显示体积与分支预览 |
| 拉取/fetch | 顶栏同步按钮 | 低 | 无需确认，完成后显示"新增 12 个提交" |
| 拉取/pull | 同步按钮下拉 | 中 | 预览将合入的提交列表 |
| 推送/push | 顶栏 ↑N 徽章 | 中 | 显示将推送的提交清单 |
| 新建分支 | DAG 节点右键「从这里分叉」 | 低 | 内联输入分支名（自动建议 `feat/` 前缀） |
| 切换分支 | 分支卡片单击 | 低 | 有未提交改动时提示三种去向（暂存/携带/放弃） |
| 删除分支 | 卡片菜单 | 中 | 显示该分支独有提交数；已合并才允许直接删 |
| 合并 | 分支卡片拖到 main 头 | 高 | 合并预览：文件冲突数、提交数、策略选择（merge/squash/rebase） |
| 变基 | 分支卡片菜单 | 高 | 显示将被重写的提交（打 rewrite 标记）+ 强制快照 |
| 打标签 | 顶栏或提交右键 | 低 | 表单：名称 + 说明 |
| 撤销提交 | 提交节点右键 | 高 | 三选项：revert（推荐，新增反向提交）/ soft reset / hard reset，各自解释后果 |
| 解决冲突 | 冲突节点红色徽章 | 高 | 三栏解决器（见 §3） |
| force-push | 仅在 push 失败后出现 | **极高** | 必须勾选"我明白这会覆盖远端历史" + 显示被覆盖的远端提交 |

**所有高风险操作前**，main 进程自动创建 `refs/atlas/backup/<时间戳>` 快照，页面顶部出现可撤销提示条（60 秒内一键回滚）。

### 三栏冲突解决器

```
┌── 我的版本 ────┬── 结果（可编辑）──┬── 对方版本 ───┐
│ 每块带复选框   │  合并结果实时预览  │  同样带复选框   │
└────────────────┴──────────────────┴──────────────┘
  [采用我的] [采用对方] [两者都留] [跳过此块]   剩余 3 / 7 块
```

逐块决策 + 剩余计数 + 一键"未决块全部采用我的"。禁止出现裸 diff 让人读。

## 3. 拖拽规格

拖拽是本产品的主交互语言。**所有拖拽结果写入 `viewMeta`（视图元数据），不改 Git 数据**——除了"合并"这一种，它明确走确认管道。

| 区域 | 拖拽行为 | 视觉反馈 | 落点结果 | 持久化 |
| --- | --- | --- | --- | --- |
| DAG 节点 | 上下拖动改泳道 | 目标泳道高亮 + 磁性吸附（≤8px） | 节点重排到此 lane | `viewMeta.laneOverrides` |
| DAG 分支标签 | 拖到顶部"固定区" | 标签缩成药丸吸附 | 该分支常驻可见 | `viewMeta.pinnedRefs` |
| DAG 画布 | 空白处拖动 = 平移；空格+拖 = 框选 | 框选半透明矩形 | 多选节点，可批量打标签 | 不持久化 |
| 时间轴 | 横向拖出时间窗 | 蓝色范围条 + 两端手柄 | 联动过滤 DAG / 热区 / 看板 | `viewMeta.timeRange` |
| 看板卡片 | 四列间拖动 | 列背景亮起，卡片倾斜 3°，投影加深 | 仅打本地状态标签（待合并/评审中/阻塞/已合并） | `viewMeta.kanban` |
| 文件树图 | 拖动分区边界 | 对齐参考线 | 自定义目录分组 | `viewMeta.treeGroups` |
| 面板 | 拖动标题栏 | 停靠预览高亮 | 重排/分屏/浮窗（dockview） | `viewMeta.layout` |
| 问题卡 | 拖到"忽略"区 | 忽略区展开成抽屉 | 该规则忽略 | `viewMeta.ignoredRules` |

**必须处理的三件事**（否则拖拽会变成负担）：

1. **撤销**：`Ctrl+Z` 撤销最近一次拖拽，所有 viewMeta 变更进同一个 undo 栈；
2. **触控与鼠标同一套**（`@dnd-kit` 的 sensor 抽象），移动端长按 400ms 进入拖拽，避免与滚动冲突；
3. **键盘可达**：聚焦节点后 `Alt+↑/↓` 移动泳道，保证不用鼠标也能操作。

## 4. 连线视觉规格

用户要求"链接也要美化"。美化不是加渐变，而是**让每条线的含义一眼可读**。

### 4.1 几何

| 类型 | 形状 | 参数 |
| --- | --- | --- |
| 继承（普通提交） | 平滑曲线 | Catmull-Rom 转三次贝塞尔，控制点偏移 = 0.35 × 垂直间距 |
| 合并 | 曲线 + 实心箭头 | 箭头置于目标节点前 8px，箭头高 6px |
| 跨泳道 | 曲线 + **交叉断口** | 与其它边相交处留 2.5px 间隙（比换色更有效） |
| 分叉区间（rebase 前后） | 虚线 | 3-3 虚线；受重写提交额外加淡红底色 |

### 4.2 颜色与语义

- 分支色相用**黄金角分配**（`hue = (n × 137.5°) mod 360`），固定饱和度 62% / 亮度 52%，相邻分支不撞色；
- 三种语义描边：主干 `main` 加粗 2.5px、活跃分支 1.8px、僵化分支 1.2px 且降饱和 40%；
- **不只靠颜色**：实线 / 双线 / 虚线同时编码三种关系，色盲安全校验（deuteranopia 模拟下仍需可辨）。

### 4.3 悬停与选中

```
未选中边        不透明度 25%
选中节点的祖先链  不透明度 100% + 描边加亮 + 宽度 +0.5px
后代链          不透明度 60%
其余            不透明度 8%（几乎消失，但保留空间感）
```

### 4.4 动效（可关）

- 最近 7 天有提交的分支，其边上跑两段渐变光点，周期 4s；
- 高亮切换 160ms `ease-out`，禁止弹性动画（会让人找不到焦点）；
- 遵守 `prefers-reduced-motion`：全部降级为静态描边加粗。

### 4.5 降级策略（性能兜底）

| 条件 | 降级 |
| --- | --- |
| 可见节点 > 3,000 | 节点变圆点，隐藏 commit message 摘要 |
| 可见边 > 3,000 | 切换"轨道渲染"：只画颜色带，不画单条边 |
| 缩放 < 0.4 | 边变直线，关闭光点与断口 |
| 缩放 > 1.5 | 显示提交标题与作者头像 |

### 4.6 外部链接的美化

产品里会出现大量外链（commit 在 GitHub 上的页面、PR、issue）。统一处理：

- 一律渲染为**行内药丸标签**（图标 + 域名缩写 + 标题），不在正文里裸露长 URL；
- 悬停显示完整域名与目标类型（提交/PR/工单），点击经确认弹窗（显示完整 URL）；
- 复制按钮常驻，复制后 1.2s 内显示"已复制"；
- 分享链接本身也走同一套药丸渲染，附带过期时间徽章。

## 5. 状态设计（零命令行产品最容易翻车的地方）

用户不会读日志，界面必须自己解释。**每种状态四要素：发生了什么 / 为什么 / 下一步点哪里 / 能不能撤销。**

| 状态 | 呈现 | 动作 |
| --- | --- | --- |
| 空（无仓库） | 首屏三卡片 + 一句"打开一个本地目录就能开始" | 三个入口按钮 |
| 索引中 | 四阶段进度条，可后台 | 「后台继续」「取消」 |
| 数据陈旧 | 顶栏黄色徽章「3 小时前」+ 全视图 8% 灰蒙版 | 徽章即按钮，点击刷新 |
| git 未找到 | 全屏引导：「使用内置 git」按钮（默认高亮） | 一键切换 |
| 目录不是仓库 | 内联提示 + 「在此初始化仓库」按钮 | 显示将创建的文件预览 |
| 权限不足 | 说明所需权限 + 「用其他账号授权」 | OAuth 重走 |
| 合并冲突 | 节点红色徽章 + 顶部横幅"3 个文件需要你决定" | 打开三栏解决器 |
| 离线（移动端） | 顶部细条「离线·显示 11-19 10:12 的快照」 | 只读，写操作禁用 |
| 索引失败 | 错误卡：失败阶段 + 原因人话 + 展开技术详情 | 「重试」「跳过该仓库」 |

## 6. 移动端适配

不是把桌面缩小，而是**只保留"看 + 审批"**：

| 桌面 | 移动 |
| --- | --- |
| DAG 多面板 | 单画布全屏 + 底部抽屉切换视图 |
| 拖拽改泳道 | 长按 400ms 拖拽；双指缩放；单指平移 |
| 四列看板并排 | 纵向滑动列表 + 顶部段控切换 |
| 分屏面板 | 无分屏，底部 Tab（总览 / 拓扑 / 问题 / 团队 / 我） |
| 右键菜单 | 长按弹出 action sheet |
| 悬停高亮 | 轻点选中（再点空白取消） |

硬约束：触控目标 ≥ 44×44px；首屏 4G 下 ≤ 4s；DAG 默认只渲染主干与 3 条最近分支（可在设置里放宽）。

## 8. 验收清单（交互层）

- [ ] 全程键盘操作可完成"打开仓库 → 定位僵化分支 → 创建合并预览"；
- [ ] 移动端单手可完成"查看问题雷达 → 忽略一条 → 刷新"；
- [ ] 任意拖拽都有 ≤8px 的吸附反馈与可撤销；
- [ ] 连线在 deuteranopia 模拟下三种关系仍可区分；
- [ ] 每种错误态都有一个可点的下一步按钮；
- [ ] 3 秒内能从任视图回到"最该处理的问题"。
